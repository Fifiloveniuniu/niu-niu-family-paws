# Calendar, pets and Spanish review

Read-only walkthrough of the running localhost:4180 demo in headless Chrome, in Spanish on desktop and phone. Every pictured customer, pet, location and stay is a labeled local test fixture. No booking was saved during this walkthrough.

- `calendar-es-desktop.png`: shared calendar controls and annotations.
- `booking-es-desktop.png`: matching booking controls, room selection and requested stays.
- `review-es-desktop.png`: itemized display-only cost estimate.
- `pet-es-desktop.png`: pet history dialog and recorded activity.
- `pricing-es-phone.png`: public pricing on a 390px phone.

The automated submission journeys additionally exercise English/Chinese/Spanish, unavailable-room controls/markers, sticky alignment, live time, capacity/privacy, booking/cancellation activity, modal tabs, multilingual saved price labels and equal customer/admin pet photo dimensions.
