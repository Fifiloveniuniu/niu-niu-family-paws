# Calendar sample profile photos

Calendar aliases are fictional. They link explicitly to existing isolated local demo profiles for photo previews; they are not real customer identities. The app reads each profile’s current private photo through the normal authenticated API. It does not bundle images, create public storage URLs, overwrite photos or infer identities from names.

The calendar, scheduling and balance screenshots contain crops of these licensed source photographs. Photo crops retain their corresponding source licenses; authors, sources and license links are recorded below and in the app’s expandable photo credits. Other test-library metadata is in `docs/test-assets/pet-photos.json`. If a demo profile’s photo changes, regenerate screenshot credits from its current metadata.
